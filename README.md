# D点攻势 (D-point Offensive)

战地风格 Minecraft 模组：占点 / 计分 / 队伍系统 / 语音通讯。

- **支持版本**：Minecraft 1.7.10（v1.1.16）、1.12.2（v1.2.2）、1.21.1（NeoForge，开发中）
- **作者**：t_55
- **许可证**：MIT
- **语言**：简体中文 / English / Deutsch / Français / Italiano / 日本語 / Русский（7 语言）

## 功能

| 模块 | 说明 |
|---|---|
| 占点方块 | 据点半径/占领时间/名称可配；大基地模式；每秒按占领差扣分 |
| 分数控制器 | PvP（初始分数/每秒扣分）与 PvE（丧尸参数）；双队对抗 / 多队伍淘汰两种模式 |
| 队伍配置器 | 自由创建队伍（默认 2 队，最多 10 队），名称与队伍方块自由匹配，出生点/背包模板配置 |
| 战场传送器 | 红石信号激活：加入对应队伍 + 替换背包模板 + 传送到出生点（换装/传送可独立开关） |
| 快捷交流 | 按 `T` 打开，多分类自定义指令 |
| 设置页 | 按 `Y` 打开，一级分类 tab：「快捷交流配置」+「HUD 配置」 |
| HUD 配置 | 分数条/罗盘的位置、大小、开关均可调并保存 |
| 语音通讯 | 内置队伍语音系统 |
| Shift 介绍 | 物品栏按住 `Shift` 查看方块详细介绍 |
| 战术标记 | 按 `M` 标记坐标，HUD 内显示方向 |

## 构建

两个版本均为 ForgeGradle 工程，需要对应 JDK：

```bash
# 1.7.10（JDK 8，Gradle 4.9+，reobf 构建）
gradle build

# 1.12.2（JDK 8，Gradle 4.9，ForgeGradle 3）
gradle build
```

产物在 `build/libs/objective-d-<版本>.jar`。
